# OPP-001 Webcam Corner Mount

**Project:** OpenPrinter

**Version:** v0.1.0-alpha

## Purpose

Replacement base for the HOON Logitech C270 webcam mount used on the Creality Ender 5 Pro.

The original mount works well but has an oversized square base which sits above the front-left aluminium extrusion and can contact the Y-axis belt, allowing the webcam to move slightly during printing.

## Design goals

* Keep the original webcam mount geometry.
* Keep the original pivot ears and camera angle.
* Replace only the base.
* Fit entirely within the triangular aluminium corner brace.
* Mount using the existing M3 corner brace bolt.
